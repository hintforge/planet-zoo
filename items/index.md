# Items -- index

**status:** research-integrated
**last_reconciled:** 2026-08-22

**Honest empty-statement (P1 confirmed):** Planet Zoo has none of the standard combat item categories (no weapons, abilities, upgrades, consumables, crafting materials, or builds) -- P1 research confirmed Stage 0's prediction with zero exceptions found across the full base-game systems pass, so no `items/<category>.md` files exist.

The game's actual "things" surfaces live elsewhere:
- **Animals** -> `animals/` (the species bestiary; the real reference surface).
- **Shops, facilities, scenery, enrichment items, staff buildings, rides** -> covered as management/building content in `mechanics.md`.

This folder stays a near-empty scaffold. If a genuinely item-shaped category emerges during play (e.g. a player repeatedly asks about a discrete enumerable object set that doesn't fit `animals/` or `mechanics.md`), promote it here from `_overflow/`.
