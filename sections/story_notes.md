## The arc, scenario by scenario

1. **Stately Home Schooling** -- Goodwin House, Bernie Goodwin's own zoo mid-renovation. Tutorial framing.
2. **The Ape-renticeship** -- Madagascar Simian Conservation Zoo, an ape/monkey breed-and-release programme.
3. **Bear Essentials** -- "Panda Park," a giant-panda-centric welfare/breeding lesson.
4. **Eye of the Taiga** -- Maple Leaf Wildlife Park, Canada.
5. **Go to Crater Lengths** -- Great Caldera Safari Park, built in/around a dormant volcano.
6. **Squeezing the Margins** -- Myers Lake Island Zoo, Greece. **Dominic Myers' first zoo** -- introduces the Myers character arc.
7. **Power Struggle** -- Myers Animal Entertainment Park, India, a repurposed casino. **Dominic Myers' image-rehabilitation arc** continues.
8. **Steeped in Pollution** -- Myers Rainforest Conservation Project, disused quarry. Myers-arc continuation.
9. **Hiring Freeze** -- "Myers Sunshine Happiness Zoo." Myers-arc continuation, employment-restriction theme.
10. **Greener Pastures** -- Nevada State Eco-Zoo. **Emma Goodwin introduced as protagonist.**
11. **Bailing Out** -- Yamaguchi Prefecture Tranquillity Zoo, Japan, debt recovery. Gold-tier climax involves adopting a named animal, "Lin-Lin."
12. **The Last Leg** -- Bernie Goodwin Memorial Zoo, Upper Bay, New York. **Series capstone**, testing all systems together.

Full per-scenario detail (objectives, missability, sources) lives in `sections/<scenario_slug>.md`, one file per scenario.
