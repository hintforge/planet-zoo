# Planet Zoo -- Controls Reference

**status:** research-integrated
**last_reconciled:** 2026-08-22

Input and control-scheme reference. Authored against **PC / Steam** (keyboard + mouse). The Console Edition (PS5 / Xbox) uses a controller scheme NOT covered here. All content `spoiler: none`, `enemy-tier: 0`, `puzzle-tier: 0`.

## Why controls matter in this game

Planet Zoo's construction system is deep and has a notorious learning curve. Most player friction is "how do I place this piece exactly where I want it," not "what does the game do." Build controls (grid snap, surface snap, advanced move/rotate, gizmos, duplication) are the single most-asked control topic.

## Camera / navigation

| Action | Input |
|---|---|
| Pan camera | W / S / A / D |
| Raise / lower camera | E / Q |
| Camera pan (alt method) | Right Mouse Button + move, or scroll-wheel-click + drag |
| Camera tilt/rotate | Left+Right Mouse Button + move, or hold scroll-wheel button + move |
| Camera zoom | Scroll wheel / Page Up / Page Down |
| Toggle Freelook camera | T (Shift = faster freelook speed) |
| Camera modes | Standard, Freelook, Explore, Scenic, Cinematic |

## Piece placement / building (priority)

| Action | Input |
|---|---|
| Place / cancel piece | Left Click / Right Click or Esc |
| Rotate (free) | Z + mouse move |
| Rotate 90 degree snap | Z (tap) |
| **Toggle Advanced Move/Rotate mode** | **X** |
| Adjust vertical height | Shift + mouse move (vertical) |
| Reset vertical height | Shift (tap) |
| Lock to surface axes | Ctrl + mouse move |
| **Toggle angle/grid snap on/off** | **Space** |
| Toggle align-to-surface | V |
| Flatten terrain on/off | K |
| Snap decorations to wall-piece centre | F |
| Select multiple pieces | Ctrl + Left Click |
| Duplicate object/building | Ctrl + D |
| Move selection | M |
| Enter Group Edit mode | R |
| Undo / Redo | Ctrl+Z / Ctrl+Y |
| Delete selected | Delete |

## Path editing

Raise/lower without placing = U/J; decrease/increase length = - / =; width = [ / ]; T-junction toggle = X; Y-junction = hold Z at junction; curved slopes = V; grid align = N; placement-suggestion snap = B.

## Terrain sculpting

Apply brush = LMB; inverse/push-pull = LMB+Ctrl; brush intensity = - / =; brush size = [ / ].

## Misc

Pause = P; sim speed = O; Help overlay = F1; Zoopedia = F3; Save/Load = F5/F9; zoo menu tabs = 0-9; Heat Maps = H; Multi-select = I; Show/hide UI = G; camera torch = L.

## Common remaps players make

- **Camera rotate: default L+R-click-drag -> many builders remap to Alt+mouse-move.** Frees both mouse buttons for placement/selection while simultaneously orbiting the camera, which matters constantly during detailed piece-by-piece building. [single source]
- **Scroll-wheel-click-drag for camera pan** is repeatedly cited as more efficient than edge-panning for two-handed building, since it keeps the cursor over the build site. [single source, corroborated independently by the Chinese guide's tip #40 -- "hold scroll wheel to rotate the view"]
- **Freelook mode over Standard mode for building**: community consensus that Freelook lets a player move around a park much quicker; Standard mode is described as "a huge flaw for building things." Functions as the community's de facto building-camera default rather than a keybind remap. [single source]
- **No Y-axis camera invert option exists** in Standard camera mode -- a genuine missing-feature complaint on the official controls guide's own comment thread. [single source]
